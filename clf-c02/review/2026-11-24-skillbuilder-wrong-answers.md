# CLF-C02 오답 노트 — 2026-11-24 (Skill Builder 공식 연습 문제)

|---|---|---|---|

## 1. 보안 그룹 무제한 접근 탐지 → Trusted Advisor

- **판별 키워드:** "보안 그룹", "무제한 액세스(0.0.0.0/0)", "점검/식별/권장"
- Trusted Advisor는 계정을 **점검**해서 비용·성능·보안·내결함성·서비스 한도에 대한 **권장 사항**을 줍니다.
  - 보안 점검 예: 0.0.0.0/0으로 열린 SG 포트, 루트 MFA 미설정, 퍼블릭 S3 버킷

| 서비스 | 하는 일 | 이 문제에서 오답인 이유 |
|---|---|---|
| **Trusted Advisor** | 모범 사례 **점검·권장** | ✅ |
| IAM | **누가 무엇을 할 수 있는지** 권한 관리 | 보안 그룹을 점검하지 않음 |
| CloudTrail | API 호출 **감사 기록** | 설정 상태를 점검하지 않음 |
| CloudWatch | 지표·로그 **모니터링** | 보안 설정을 점검하지 않음 |

> 💡 실무 비유: Trusted Advisor = 보안·비용 **진단 리포트**(취약점 점검표).
> ⚠️ IAM 정책 ≠ 보안 그룹. **보안 그룹 = 네트워크 방화벽**(포트/IP), **IAM = API 권한**.

---

## 2. 전송 중 암호화 → ACM

- **판별 키워드:** "전송 중(in transit)", "SSL/TLS", "HTTPS", "인증서"
- ACM이 SSL/TLS 인증서를 발급·갱신 → ELB/CloudFront에 붙여 HTTPS 적용

| 암호화 구분 | 서비스 |
|---|---|
| **전송 중** (네트워크) | **ACM** (TLS 인증서) |
| **저장 시** (디스크·S3·DB) | **KMS** (암호화 키) |

| 오답 보기 | 실제 용도 |
|---|---|
| Shield | **DDoS** 방어 (암호화와 무관) |
| Security Hub | 보안 상태 **종합 대시보드** |
| RAM (Resource Access Manager) | 계정 간 **리소스 공유** |

> 💡 실무 비유: Nginx/Apache의 `ssl_certificate` 인증서를 AWS가 발급하고 자동 갱신해 주는 것이 ACM.

---

## 3. 거버넌스 중앙화 + 결제 통합 → Organizations 🔁

- **판별 키워드:** "여러 계정", "중앙 집중", "결제 통합", "부서별 계정"
- 정답 문장: 관리 계정에서 **모든 기능이 활성화된** Organizations 조직을 만들고 → 나머지 계정을 **초대**
  - "모든 기능" 모드 = **통합 결제 + SCP**(거버넌스)
  - "통합 결제만" 모드 = 결제 통합만 됨 (SCP 없음)

| 오답 보기 | 왜 안 되는가 |
|---|---|
| Cost and Usage Report | 비용 **보고서**일 뿐, 결제 통합·거버넌스 ❌ |
| Systems Manager OpsCenter | 운영 이슈 관리, 결제와 무관 |
| IAM Identity Center (계정마다 따로) | SSO 접근 관리, 결제 통합 ❌, "각 계정에서 따로" = 중앙화 아님 |

> 🧠 **"계정이 여러 개" + "결제" 또는 "중앙"이 나오면 → 무조건 Organizations**

## 4. 팀 전체에 경고 발송 → SNS

- **판별 키워드:** "알림", "경고 전송", "이메일·SMS·푸시", "구독자에게"

| 서비스 | 한 줄 정의 | 비유 |
|---|---|---|
| **SNS** | 구독자에게 **알림을 뿌림** (Pub/Sub, 1:N) | 단체 문자 발송 |
| SQS | 메시지 **대기열**, 시스템 간 분리 (Pull) | 작업 큐 (JMS Queue) |
| EventBridge | 이벤트를 **규칙으로 라우팅**하는 이벤트 버스 | 이벤트 라우터 |
| Amazon Connect | 클라우드 **콜센터** | 고객센터 전화 시스템 |

> 💡 EventBridge는 이벤트를 **어디로 보낼지 정하는** 서비스이고, 사람에게 직접 알림을 보내는 것은 SNS입니다.
> 실무 패턴: `EventBridge(이벤트 감지) → SNS(이메일 발송)`. 문제에서 "**경고를 보낸다**"면 SNS.

---

## 학습 포인트 (Step-by-Step)

1. **"점검/권장"이 나오면 Trusted Advisor.** 감사(CloudTrail), 모니터링(CloudWatch)과 구분합니다.
2. **암호화는 "전송 중 = ACM / 저장 시 = KMS"**로 짝지어 외웁니다.
3. **Organizations 반복 오답:** "여러 계정 + 결제/중앙"을 보면 바로 Organizations를 고릅니다.
4. **메시징 4종:** SNS = 알림 발송, SQS = 대기열, EventBridge = 이벤트 라우팅, Connect = 콜센터.
